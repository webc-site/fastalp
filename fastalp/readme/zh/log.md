## 更新日志

### v0.1.48

- **无依赖查表并发解重构与 2KB 相对偏移编译期表**：<br>
  在时序游程重复（Repeat）展开中，利用 `const fn` 编译期预计算 256*8 字节的相对偏移表 `REPEAT_OFFSETS_LUT`（2KB，100% 常驻 L1D 缓存）。彻底打破逐位移位加法的 8 阶段串行数据依赖链，使 8 槽位目标数据由 CPU Load 端口完全并发加载写入；完全消除 `prev` 状态变量，首字 `word == 0` 直通零拷贝，尾块自动分块批量展开。
- **0 位宽常量广播 Soundness 治理与 LLVM 向量化直写**：<br>
  针对 `bit_width == 0` 的常量块与平直差分块，全面采用 `MaybeUninit` 切片包装执行 `fill`，既彻底消除了在未初始化内存上构造非 `MaybeUninit` 引用的 Tree Borrows / Stacked Borrows 未定义行为（UB）风险，又精准触发编译器底层 SIMD 广播填充（ARM64 `st1` / x86 `vmovups`），吞吐直达物理总线极限（80~95 GB/s）。
- **4-Run 跨度采样覆盖与动态高危异常惩罚机制**：<br>
  将样本抽取重构为覆盖序列 0%、33%、66%、100% 区间的 4 个连续 Run，保留局部一阶差分特征的同时杜绝首部常数偏差；定义 `HIGH_EXC_THRESHOLD = 3` 与 `HIGH_EXC_PENALTY_MULT = 4`，引入 `calc_exc_cost` 动态高危异常惩罚机制，彻底消除采样选错参数导致的 1024 块突破 128 异常上限及恶性回退 RAW。使真实世界数据集 `cms1` 压缩比由 1.14x 跃升至 1.59x（+39%）、解压吞吐跃升至 29.5 GB/s（+150%），`medicare1` 彻底消除 RAW 回退稳定进入十进制高压状态。
- **异常点平滑回填单步定位优化**：<br>
  在编码扫描内核中实施前值平滑回填（Fill-Forward），异常点原地继承前一有效编码值，差分恒为 0；利用 `exceptions` 的天然升序性，使用标准库原生单步迭代器 `position` 替换原先在 `0..count` 上的二分查找，将首有效元素查找复杂度从 O(count · log K) 降至 O(K)。

### v0.1.45

- **基准值编码模式双级动态异常预算**：<br>
  重构离群点剪枝流水线，解耦前置快筛与基准值（FOR）独占优化；在前置剪枝阶段严格将异常预算限制在十六个，保护时序差分（Delta）模式不受过多离群点拖累；在判定不走 Delta 后，独占放宽异常预算至三十二个，深入收窄基准值位宽。在保证严格成本单调递减的前提下，显著压缩带长尾尖峰的数据集位宽（如 `medicare9` 位宽由 9 降至 8，压缩比提升至 6.73x，解码吞吐提升至 40.96 GB/s）。
- **差分回填污染清洗与零开销状态机闭环**：<br>
  在 FOR 模式下引入异常点位置原子重置，彻底消除评估 Delta 时前驱回填对离群点直方图统计造成的双重计数与错误短路；优化剪枝缓存状态机流转守卫，实现首块多轮自适应探索与后续块零开销直接命中。
- **位宽上限防守与健全性保障**：<br>
  在目标位宽应用内核中增加六十四位及以上位宽的防守式上限保护，杜绝极端位移溢出隐患；消除未剪枝分支的冗余空间重算，代码全面通过严格审查与内存安全审计。

### v0.1.44

- **时序重复游程无分支展开**：<br>
  证明并应用位图状态转移恒等式，将重复展开中逐位的条件分支判断彻底消除为单指令算术运算与指针直写；配合八元素展开直写宏，消除流水线气泡，带行程重复的数据集解码吞吐暴涨 15% ~ 24%（如 `food_prices` 达 20.8 GB/s，`nyc29` 达 18.2 GB/s）。
- **低位宽解包十六元素宽加载**：<br>
  在 1、2、4 位宽解包内核中全面推行十六元素指令级并行（ILP）双倍展开；利用单次 16 位、32 位与 64 位宽字读取直解，极大降低内存加载频次，饱和超标量微架构执行单元。
- **全局展开宏体系扩展**：<br>
  在 `src/macros.rs` 中引入 `unroll_16!` 与 `write_16!` 宏，消除手动多路展开样板，彻底清理多余常量与切片死代码。

### v0.1.43

- **四步线性递推前缀和二叉树**：<br>
  在差分解码消费器中利用代数环补码加法结合律与交换律，预计算极小差分步长常数向量，将连续累加依赖链解耦为同构四元组平衡二叉树，消除逐项重复加法，跨块循环依赖延迟压缩至单指令周期。
- **十六元素指令级并行展开**：<br>
  在八位位宽解包与差分扫描中全面推行十六元素双路并行加载与阶梯处理，饱和利用多发射超标量执行端口；差分极值规约树深度压缩至四层，关键路径时延降低七成以上。

  消除真实双精度解码中每次调用一万六千字节的栈内存清零开销，改为未初始化内存原地切片与十六路位或展开，实现零拷贝原位融合。

  采样阶段在前置快筛判定非十进制特征时即刻熔断高延迟浮点除法分支，增加前置快速异常熔断，杜绝无效计算开销。
- **宏元编程重构与死代码消除**：<br>
  清理全部向后兼容宏别名，设计元编程宏统一展开全位宽单态化跳转表，大幅削减代码体积与样板重复。
